# 우리 반 자리 바꾸기

초등학교 교실에서 쓰는 **자리 바꾸기 프로그램**입니다.
자리를 섞으면 책상마다 알이 놓이고, 알을 하나씩 깨면서 누가 어디에 앉는지 공개합니다.

## 바로 쓰기

### 👉 https://hsm4926.github.io/jari-bakkugi/

설치 없이 링크만 누르면 바로 씁니다. **즐겨찾기에 넣어 두세요.**

### 바탕화면 아이콘으로 만들기 (권장)

크롬이나 엣지로 위 주소를 연 다음, 주소창 오른쪽 끝의 **설치 아이콘(⊕)** 을 누르거나
`⋮` → **앱으로 설치** 를 고르세요.

- 바탕화면에 **책상 아이콘**이 생깁니다
- 주소창 없이 **자기 창**으로 떠서 교실 TV 에 띄우기 좋습니다
- 한 번 설치하면 **인터넷이 끊겨도** 그대로 돌아갑니다

## 무엇이 되나요

- 모둠별 자리, 또는 모둠 없이 책상만 줄 세우기
- 학생 명단 입력 · 남녀 구분 (캐릭터 모습이 달라집니다)
- 자리 섞기 → 알을 **순서대로 / 랜덤 / 한 번에** 공개
- 알마다 번호가 붙어 «몇 번 열어 볼까?» 하고 아이들이 고를 수 있습니다
- 미리 자리를 정해 두는 기능
- 프리셋 — 배치 + 명단 + 사전 자리를 통째로 저장해 두고 불러오기

명단과 설정은 **그 컴퓨터의 브라우저에** 저장됩니다. 서버로 보내지 않습니다.
다른 컴퓨터로 옮기려면 `설정 ▸ 저장 · 불러오기` 에서 파일로 내보내고 불러오세요.
